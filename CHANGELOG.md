# Changelog

All notable changes are documented here. This project follows semantic versioning.

## 1.0.0 — 2026-09-27

### Added

- Certificate Transparency subdomain discovery and RDAP registration metadata.
- DNS, HTTP/S, TLS, security-header, redirect, title, favicon, and technology observations.
- Expanded typosquatting variants including Unicode homoglyphs and keyword affixes.
- Immutable scan snapshots and grace-based `DISAPPEARED` state.
- DOM-structure and screenshot perceptual similarity signals.
- Playwright screenshot retention and protected screenshot delivery.
- PostgreSQL, Redis/RQ workers, scheduled scans, retries, health checks, and metrics.
- API-key protection, request rate limiting, SSRF controls, CSP, and structured JSON logs.
- Responsive React interface, dark/light mode, demo workspace, and professional screenshots.
- Unit, PostgreSQL, Redis worker, scan-flow, migration, browser, and Docker Compose E2E checks.

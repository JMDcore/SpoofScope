# SpoofScope v1.0.0

The first stable release of SpoofScope delivers a self-hosted defensive monitoring workflow for authorized domains.

## Highlights

- Passive attack-surface observations across Certificate Transparency, DNS, HTTP/S, TLS, technologies, and security headers.
- Defensive typosquatting generation enriched with DNS, RDAP, TLS, redirects, and page evidence.
- Explainable page and visual similarity signals, with optional Playwright screenshots.
- Immutable historical snapshots and explicit `NEW`, `CHANGED`, `UNCHANGED`, and grace-based `DISAPPEARED` states.
- Responsive React console and public product demo backed by FastAPI, PostgreSQL, Redis/RQ, and APScheduler.
- Reproducible Docker Compose deployment with health checks, API-key protection, bounded collection, retention, metrics, and CI.

Scores prioritize analyst review; they are not phishing or maliciousness verdicts. Monitor only domains you control or are authorized to assess.
